## 输出要求

请根据用户反馈修订 PRD，输出符合系统提示词中定义的 JSON 格式的完整 PRD 文档。确保：

1. 针对性地修改用户反馈中提到的问题，不要丢失原 PRD 中未被质疑的内容
2. 如果用户要求新增功能，在 features 中补充对应条目
3. 如果用户要求修改已有功能，更新对应 feature 的描述、用户故事和验收标准
4. 如果用户要求删除功能，移除对应条目并调整模块划分
5. 保持 feature ID 的连续性和模块关联的一致性
6. 验收标准必须具体可量化，避免模糊描述
7. 更新后的 PRD 必须包含完整的 5-section 结构 + features/modules

## 质量检查

- 修订后的验收标准是否具体可测试？
- 非功能性需求是否有具体数字？
- 是否避免了"快速"、"易用"等模糊描述？
