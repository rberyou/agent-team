## 架构设计文档
{{designDoc}}

请输出 JSON 格式的任务拆分方案：

```json
{
  "modules": [
    {
      "name": "模块名称",
      "description": "模块职责描述",
      "interfaces": ["对外接口列表"],
      "dependencies": ["依赖的其他模块"]
    }
  ]
}
```

确保：
1. 每个模块职责单一、边界清晰
2. 模块间通过明确的接口通信
3. 覆盖架构设计中的所有组件
