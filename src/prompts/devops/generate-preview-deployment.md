## Requirements

Generate a **preview** environment deployment configuration that includes:
1. **Preview URL**: The URL where users can access the running preview
2. **Services**: All deployed services with their status and ports
3. **Build Info**: Version, build time, and deployed modules
4. **Start Command**: How to start the preview environment

The preview deployment should enable the user to interact with the full system for acceptance testing.
